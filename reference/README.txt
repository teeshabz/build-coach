Photos of YOUR actual gear. The filename becomes the label the model sees,
so name them for what they show:

  metal-mode.jpg          stud finder switch set to metal
  wood-mode.jpg           stud finder switch set to wood/stud
  direct-screw-in-hook.jpg   the hook that goes straight into wood
  drywall-anchor.jpg      the drywall mounting piece
  stud-found.jpg          what the display looks like when it detects wood

Dashes become spaces. A leading number is stripped, so "01-metal-mode.jpg"
labels as "metal mode" and just controls the order.

notes.txt (optional) is free text in your own words - anything the photos
don't show. For example:
  The mode switch is on the left side. When it finds wood the display
  shows a solid bar and it beeps twice. The drywall piece is the one
  with the plastic wings.

This file is ignored. Only images and notes.txt get sent.
